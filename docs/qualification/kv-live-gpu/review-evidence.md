## Practical limits

The evidence establishes selected native BF16 source/cache slices and their addresses on this one dense Qwen3 runtime. It does not establish every tensor element, FP16 execution, quantized or alternative cache layouts, multi-GPU operation, individual-token/head latency, leak freedom or profiler overhead magnitude. The docs and UI preserve these boundaries. The four-token outputs demonstrate inference/recording correctness, not response quality. Existing authored fixtures remain useful regression evidence and are excluded from the production demo catalog.

The full unit/build checks are owned by the implementation workflow; this review inspected their raw logs and independently reran artifact assessments rather than duplicating the full suite. No additional runtime rerun is required by the inspected integration findings.
