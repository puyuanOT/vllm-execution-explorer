# GPU acceptance evidence

Each directory in this tree preserves a completed GPU recording as structural
evidence. Acceptance bundles contain a manifest, an event stream, an integrity
report, environment notes, and checksums. Prompt text, generated text, token ID
payloads, credentials, and machine-specific absolute paths are excluded.
